1. Ключевые системы (кратко)
- Статы: Calm (Спокойствие)/Anxiety (Тревога), Vulnerability (Уязвимость), Willpower (Сила духа), SocialEnergy (Соц. энергия), Reputation.
- Телефонный интерфейс (интерактивный HUD).
- Паника/дыхание мини‑игра.
- SPEAK — школьная соцсеть (посты, сторис, скрытые аккаунты).
- Система отношений (Gilbert, Dylan, Eva, прочие).
- Система триггеров/логики: события, которые меняют статы, открывают скрытые реплики и дают доступ к вариантам.

---
 
2. Шкала эмоций — поведение и пороги
- Calm / Anxiety (primary)
  - 100% — полностью в безопасности, диалоги без дрожи.
  - 50% — лёгкие реакции, диалоговые варианты ограничены.
  - 20% — появление панических подсказок, высокая вероятность паники.
  - 0% — обморок/чёрная сцена, пропуск к худшему пути.
- Vulnerability (0–100)
  - Чем выше → чаще случайные панические события, меньше сил сопротивляться.
  - Уменьшается при поддержке, правильном выборе, дыхании.
- Willpower (0–100)
  - Влияет на доступ к «скрытым» вариантам и финалам.
  - Растёт при добрых действиях, помощи от Гильберта/Дилана, успешном дыхании.
- SocialEnergy (0–100)
  - Отражает желание общаться, влиять на SPEAK и смогу ли нажать SOS.
- Reputation (computed)
  - Вычисляется из действий; влияет на контент в SPEAK.

---
 
3. Интерфейс телефона (поведение)
Главное меню:
- Messages, Gallery, Evidence, Map, Music, Diary, SOS, SPEAK, Mail, EmotionsSettings, Breathe.

Музыка: каждый трек имеет эффект на статы при включении и поддерживает +/− эффекты в панике.
Diary: отображает заметки и метаданные, меняет почерк (CSS эффекты) при низкой стабильности.
SOS: работает только если взаимоотношения/репутация/соц. энергия позволяют — реализовать проверку (threshold).
Breathe: запускает антистресс‑игру (круг/ритм). Успех даёт значительные снижения Anxiety.

---
 
4. Паническая атака — улучшенная механика
- Триггер: Anxiety >= 80 OR Vulnerability >= 75 OR конкретный event.
- UI: экран дрожит + красный overlay + движение текста (marquee/particle).
- Игрок может:
  1) Нажимать кнопку дыхания в ритм;
  2) Включить музыку (если доступна) — уменьшает скорость ухудшения;
  3) Позвать NPC (SOS / позвать Гильберта/Дилана) — если отношения позволяют;
  4) Спрятаться в меню телефона (переход в Phone UI) — временная пауза.
- Успех: -Anxiety (значительно), +Willpower (небольшое).
- Провал: blackout → переход к плохому пути или ухудшение репутации.

Алгоритм дыхания (пример):
- Требуется пройти N циклов (нарастающая сложность).
- Каждая правильная последовательность (inhale → hold → exhale) даёт 1 очко.
- Таймер: maxDelta между шагами; промах — штраф.

5. Диалоговая система и варианты
Категории реплик:
- Soft (💙) — улучшает доверие, снижает тревогу у других.
- Sassy (🔥) — повышает уверенность, может увеличить конфликт.
- Vulnerable (💔) — проникает в сердце NPC, но повышает уязвимость.
- Silence (❓) — часто повышает тревогу.
- Hidden (🖤) — доступен при высоких тревоге/низкой спокойствии (специальный эффект).

Эффекты:
- Каждая реплика изменяет статы и отношения; могут открываться короткие скрипты (SFX, camera shake).
- Контекст: реплики могут иметь «preconditions» (например, Hidden доступен когда Anxiety>70).

6. Романные ветки (основные)
- Dylan: "плохой парень, который пытается измениться".
  - Триггеры любви: поддержка, признания, выборы в панике.
  - Его события: ревность, защита, раскрытие травмы.
  - Влияние: даёт "огненную" защиту, но может вызвать общественные проблемы.
- Gilbert: мягкая опора.
  - Триггеры: благодарность, доверие, совместные расследования.
  - Влияние: стабильный защитник, помогает юридически и морально.

7. Финалы (условия)
- Gilbert HE: Willpower >= 70, отношенияGilbert high, evidence раскрыты.
- Dylan HE: Willpower >= 70, отношенияDylan high, скрытая ветка открыта.
- Bad End: Anxiety≥95 OR Calm≤5 и неудавшаяся паника → Беатрис уезжает.
- Secret End: Teacher tie revealed, специальные условия по evidence и отношению к Dylan.

8. UI-руководство
- Стиль: minimal, glassmorphism, iOS-like.
- Цвета (пример):
  - background: #E1E8F0 (мягкий)
  - accent calm: #AEC6FF
  - danger: #FF8591
  - neutral window: #FFDCA7
  - support: #C8F7DC
- Анимации:
  - Buttons: transform scale 1.05 on press.
  - Panic: shake + blur + red overlay + moving negative phrases.
  - Notifications: subtle slide + fade.
- Accessibility:
  - Высокая контрастность опционально.
  - Клавиатурные макросы для дыхания / быстрых выборов.

9. Техническая архитектура и план реализации
Технологии:
- Frontend: HTML/CSS/JS (Vanilla) или фреймворк (Vue/React) для масштабирования.
- Data: JSON-конфиг + localStorage для сохранений; позже API для совместной игры.
- Assets: web-оптимизированные изображения (WebP), OGG/MP3 для звука.

План (микро‑таски):
- M0 (1–2 дн): Подготовить дизайндок + конфиг (готово).
- M1 (3–7 дн): Core engine — scene manager, state management, dialog engine.
- M2 (3–5 дн): Phone UI + Music + Diary + SOS.
- M3 (4–8 дн): Panic mini-game + animations.
- M4 (5–10 дн): Romance branches + testing.
- M5 (2–4 дн): Polish UI, accessibility, assets.
- M6: Release / build / pack (Ren'Py porting if needed).
