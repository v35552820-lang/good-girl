# Тени новой школы — Проект

Это репозиторий прототипа и геймдизайна визуальной новеллы "Тени новой школы".

Содержимое:
- DESIGN.md — детализированный геймдизайн (системы, UI, механики).
- game-config.json — начальные статы и конфигурация.
- src/css/ui-variables.css — базовые UI-переменные и компоненты.
- index.html — прототипный демонстрационный файл (при наличии).

Как запустить:
1. Клонировать репозиторий.
2. Открыть index.html в браузере (если он есть) для локальной проверки прототипа.
3. Для разработки: подключить src/js/engine.js (будет добавлен по запросу).

Дальнейшие шаги:
- Реализовать engine.js (scene manager, диалоговый движок).
- Добавить ассеты в /assets (sprites, bg, audio).
- Разбить задачи на Issues/Milestones.
